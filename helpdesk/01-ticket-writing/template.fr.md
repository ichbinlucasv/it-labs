# Modèle de ticket

[English](template.md) · **Français** · [Deutsch](template.de.md)

```text
Titre :       [Composant] Symptôme court — qui/où est touché
Demandeur :   Nom, équipe, contact (téléphone/Teams)
Actif :       Nom d'hôte / n° d'inventaire / version d'OS
Catégorie :   Matériel | Logiciel | Réseau | Compte/Accès | Sécurité
Impact :      Un utilisateur | Une équipe | Tout le site
Urgence :     Peut travailler | Dégradé | Ne peut pas travailler
Priorité :    P1–P4 (matrice impact × urgence)

Description :
  Ce que l'utilisateur signale, dans ses mots (citation), et depuis quand.

Étapes pour reproduire :
  1. ...
  2. ...

Attendu et constaté :
  Attendu : ...
  Constaté : ... (message d'erreur exact / code / référence de capture)

Dépannage déjà fait :
  - [heure] action -> résultat
  - [heure] action -> résultat

Contournement :
  ...

Prochaine action / responsable :
  ...

Résolution (à la clôture) :
  Cause, correctif appliqué, vérification avec l'utilisateur, lien vers l'article de KB.
```
