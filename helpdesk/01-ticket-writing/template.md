# Ticket template

**English** · [Français](template.fr.md) · [Deutsch](template.de.md)

```text
Title:        [Component] Short symptom — who/where affected
Requester:    Name, team, contact (phone/Teams)
Asset:        Hostname / asset tag / OS version
Category:     Hardware | Software | Network | Account/Access | Security
Impact:       Single user | Team | Whole site
Urgency:      Can work | Degraded | Cannot work
Priority:     P1–P4 (from impact × urgency matrix)

Description:
  What the user reports, in their words (quoted), plus when it started.

Steps to reproduce:
  1. ...
  2. ...

Expected vs actual:
  Expected: ...
  Actual:   ... (exact error message / code / screenshot reference)

Troubleshooting done:
  - [time] action -> result
  - [time] action -> result

Workaround:
  ...

Next action / owner:
  ...

Resolution (on closure):
  Root cause, fix applied, how verified with the user, KB article link.
```
