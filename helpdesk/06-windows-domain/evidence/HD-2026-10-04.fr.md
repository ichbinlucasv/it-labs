```text
Titre :       [GPO] Lab-Workstation-Hardening liée et vide — WIN11-SOC
Demandeur :   Contrôle du lab. Personne au téléphone. C'est moi qui l'ouvre.
Actif :       WIN11-SOC / Windows 11 Enterprise Evaluation 10.0.26200 / 192.168.122.20
Catégorie :   Logiciel
Impact :      Un seul poste (un client du lab)
Urgence :     Peut travailler
Priorité :    P4

Description :
  J'attendais que Lab-Workstation-Hardening s'applique sur l'OU des postes.
  Ce n'est pas le cas. Constaté le 4 oct. 2026, horloge de l'invité.
  Dernière modification de la GPO : 09/05/2026 19:26:48.

Étapes pour reproduire :
  1. Sur WIN11-SOC : gpresult /SCOPE COMPUTER /R
  2. Get-GPOReport -ReportType Xml pour Lab-Workstation-Hardening
     et pour Lab-Logon-Banner

Attendu / constaté :
  Attendu : Lab-Workstation-Hardening dans la liste appliquée, avec des paramètres.
  Constaté : liste appliquée = Default Domain Policy, Lab-Logon-Banner,
             Lab-PowerShell-Logging, Lab-Region-Keyboard.
             Lab-Workstation-Hardening : bytes=7140 ExtensionData=0.
             Elle est liée sur OU=Workstations et AllSettingsEnabled.
             Lab-Logon-Banner : bytes=8006 ExtensionData=1, et gpresult la liste.

Dépannage fait :
  - 04.10.2026 00:56:39, horloge de l'invité. gpresult /SCOPE COMPUTER /R.
    Stratégie depuis DC01.lab.local.
    DN de l'ordinateur : CN=WIN11-SOC,OU=Workstations,DC=lab,DC=local.
    La GPO de durcissement n'est pas dans la liste appliquée.
  - Le même soir. Lien au domaine : les quatre GPO ci-dessus.
    OU=Workstations ajoute Lab-Workstation-Hardening.
  - Get-GPOReport -ReportType Xml : durcissement ExtensionData=0,
    bannière ExtensionData=1.

Contournement :
  Aucun. Le client reçoit quand même les quatre GPO du domaine.
  L'ouverture de session n'est pas bloquée.

Prochaine action / responsable :
  Moi. Je laisse la GPO vide jusqu'à ce que j'ajoute un vrai paramètre
  et que je relance gpresult. La remplir au hasard ferait croire que
  le lab est fini.

Résolution (à la clôture) :
  Pas clos. La cause est une GPO vide, pas une erreur de traitement.
  Pas de correctif, volontairement.
```
