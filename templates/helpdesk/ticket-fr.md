# Ticket (français)

Même chose que [ticket.md](ticket.md), pour un desk en France. Je garde
l'erreur exacte dans la langue où elle s'est affichée.

```text
N° :
Ouvert le (heure locale) :
Demandeur (nom, service, téléphone ou Teams) :
Poste (nom, OS) :

Mots de l'utilisateur :

Depuis quand :
Qui est touché (une personne / une équipe / le site) :
Peut-il travailler ?   oui / dégradé / non

Ce que j'ai fait :
- [heure]  ->
- [heure]  ->

Message d'erreur exact :

Contournement :

Prochain acteur (moi / N2 / éditeur) :
Ce qu'il lui faut (un paragraphe) :

Clôture :
Cause :
Correctif :
L'utilisateur a confirmé ?  oui / non / message laissé
```

Pas de mot de passe dans le ticket. J'écris « mot de passe réinitialisé,
changement obligatoire à la prochaine ouverture » ou « secret temporaire
donné par téléphone, non noté ici ».
