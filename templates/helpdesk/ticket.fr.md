# Ticket

[English](ticket.md) · **Français** · [Deutsch](ticket.de.md)

Plus court que le modèle complet dans
[helpdesk/01](../../helpdesk/01-ticket-writing/template.md). J'utilise celui-là
quand le ticket sera audité. J'utilise celui-ci pendant que je m'entraîne à
aller vite.

```text
ID :
Ouvert le (heure locale) :
Qui a demandé (nom, équipe, comment la personne a contacté) :
Équipement (nom, OS) :

Ses mots (citation) :

Depuis quand :
Combien de personnes :
Peuvent-ils travailler ?   oui / dégradé / non

Ce que j'ai essayé :
- [heure]  ->
- [heure]  ->

Erreur exacte (coller) :

Contournement, s'ils attendent :

Prochain responsable (moi / 2e ligne / fournisseur) :
Ce dont cette personne a besoin de ma part (un paragraphe, pas « voir plus haut ») :

Clôturé :
Cause :
Correctif :
L'utilisateur a confirmé ?  oui / non / message laissé
```

Je ne mets pas le nouveau mot de passe dans le ticket. J'écris « réinitialisé,
l'utilisateur doit changer à la prochaine ouverture » ou « secret temporaire
donné par téléphone, pas stocké ici ».
