# Note IOC

[English](ioc-note.md) · **Français** · [Deutsch](ioc-note.de.md)

Je defange avant que ça ne quitte ma machine. Style `example.com` : `example[.]com`,
`hxxp://`, `[.]` dans les IP si la note est collée dans un chat.

```text
Cas :
Vu à (UTC) :
Où (quel journal, quel hôte) :

Indicateur (defangé) :
Type :  ip / domaine / url / hash / e-mail / autre

Ce qu'il faisait dans le journal (une ligne) :

Recherches que j'ai faites :
- [ ] réputation du hash ou du domaine, nom du site :
- [ ] vu sur d'autres hôtes de ce labo ?  oui / non / pas cherché

Assez sûr pour le mettre dans le ticket ?  oui, defangé / non, trop brut

Je n'ai pas téléchargé la charge utile sur le PC que j'utilise tous les jours.
VM isolée si je dois ouvrir un échantillon : nom de la VM, ou « pas ouvert ».
```
