# IOC-Notiz

[English](ioc-note.md) · [Français](ioc-note.fr.md) · **Deutsch**

Ich entschärfe, bevor das meine Maschine verlässt. Stil `example.com`: `example[.]com`,
`hxxp://`, `[.]` in IPs, wenn die Notiz in einen Chat kommt.

```text
Fall:
Gesehen um (UTC):
Wo (welches Log, welcher Host):

Indikator (entschärft):
Typ:  ip / Domäne / url / Hash / E-Mail / sonst

Was es im Log tat (eine Zeile):

Nachschlagen, das ich gemacht habe:
- [ ] Reputation von Hash oder Domäne, Name der Seite:
- [ ] auf anderen Hosts in diesem Labor gesehen?  ja / nein / nicht gesucht

Sicher genug für das Ticket?  ja, entschärft / nein, zu roh

Die Nutzlast habe ich nicht auf den PC heruntergeladen, den ich jeden Tag nutze.
Isolierte VM, wenn ich eine Probe öffnen muss: Name der VM, oder „nicht geöffnet“.
```
