# Passation de poste

[English](shift-handover.md) · **Français** · [Deutsch](shift-handover.de.md)

```text
Date / UTC :
Je (prends / quitte) la file.
Dernière personne :

Ouvert, encore à moi ou à eux :
- ID / nom d'alerte / équipement / pourquoi ce n'est pas clos / prochain contrôle

Bruit qu'on a déjà convenu d'ignorer aujourd'hui (nom de la règle, jusqu'à quand) :

Quelque chose de cassé dans les outils (SIEM, EDR, VPN) :

Qui est d'astreinte si ça empire :
```

Si je laisse une ligne qui dit « ça a l'air mauvais, pas sûr », je n'ai pas
fait la passation. J'écris le prochain contrôle.
