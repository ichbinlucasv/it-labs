# ⚠️ SYNTHETIC sample logs

Every file in this folder was **generated by hand/script for training
purposes**. They do not come from a real incident or a real organisation.

- Host names, users, domains and IPs are fictional (`example.com`,
  `example.net`, RFC 5737 addresses, RFC 1918 lab LAN).
- Hashes are placeholders (`000…0001`) — they do not identify any real file.
- The "encoded PowerShell" decodes to `Write-Output 'SYNTHETIC LAB EVENT - harmless'`.
- Each JSON event carries `"_synthetic": true`.

| File | Format | Content |
|------|--------|---------|
| `sysmon.synthetic.jsonl` | JSON lines, Sysmon field names | Workstation `WS-COMPTA-07`: macro document → PowerShell → download → Run-key persistence → beaconing → discovery (+ benign noise) |
| `security-4625.synthetic.jsonl` | JSON lines, Windows Security field names | Failed logons (4625) against `SRV-FILES-01` from an external address, plus normal user typos |
| `auditd.synthetic.log` | Raw Linux audit log format | Server `web01`: SSH password guessing → login as `deploy` → download to `/tmp` → execution → crontab → denied `/etc/shadow` read |
